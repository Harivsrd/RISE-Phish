3. Privacy & Ephemeral Data Policy

RISE-Phish is engineered with strict data minimization principles.

  • Zero Credential Collection: Never collects passwords, authentication tokens, session cookies, or form inputs.
  • No Inbox Harvesting: Only inspects the currently open message; never reads surrounding inbox lists or unread emails.
  • Ephemeral Processing: Email text is analyzed in memory; raw message content is never written to persistent database storage.
  • SSRF Hardened: Embedded links targeting private, loopback, link-local, or cloud metadata IPs are blocked prior to crawling.
